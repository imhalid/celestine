# 04 — Not sayfası

Sayfanın kendisi (başlık, özellikler, bloklar, katlama, yan panel, etiketler, kapak, sayfa gömme) yapıldı. Aşağıdakiler
Thymer'de olup bizde olmayanlar.

## Sayfa [görüldü]

- **Sayfa menüsü (`…`)**: Set Title & Icon (sayfa ikonu), Pin, **Hide Properties Section** (özellikler bölümünü gizlemek).
- **Özellikler bölümü**: `⚙` "Property view options".

## Satır tipleri ve işlemleri [görüldü: komut paleti]

| Tip | Ne |
|---|---|
| Console / Flames / Neon Banner | animasyonlu ASCII başlık |
| Link Icon / Button | bağlantıyı düğme ya da ikon olarak göster |
| Columns | blokları yan yana dizer (bkz. [15](15-bloklar-denemesi.md): yapmıyoruz) |
| Code Block | **sözdizimi renklendirmeli** kod (bizim kod bloğumuzda renklendirme yok) |
| Attachment | resim dışı dosya |
| Live Query | eşleşen sonuçları canlı gösteren sorgu |

Satır üzerinde işlemler: **Zoom in** (⌥↓, satırı tek başına açar), **Open Aside** (⌘↵, satırı yan bölmede), **Pin Line**,
**Line Options Menu** (⌃Space, klavyeden), **Indent / Deindent tree** (⌘; / ⌘⇧;), **Link to…** (satırlara da),
**Show line info**.

Yapıştırma: Paste as HTML / **Markdown** (⌘⌥V) / Text. Kopyalama: Copy as Markdown / HTML / Text, Copy Reference,
Copy Transclusion (satırı başka yere canlı gömmek için).
